# 💪 FitLog - Workout Library & Gym Companion

FitLog is a dark, focused gym companion and workout library built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Features

- **Workout Library**: Browse lifts covering every major muscle group.
- **Custom Daily Plan**: Add workouts to today's plan with exercise, duration, and calorie tracking.
- **Save for Later**: Keep a curated list of saved lifts to tackle in future sessions.
- **Responsive Dark Design**: Tailored dark-mode UI optimized for desktop, tablet, and mobile devices.
- **Instant Feedback**: Toast notifications powered by `react-hot-toast` for seamless user feedback.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Notifications**: [React Hot Toast](https://react-hot-toast.com/)

## 🏁 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
